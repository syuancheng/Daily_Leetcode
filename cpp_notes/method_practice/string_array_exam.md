# 字符串、数字与数组基础练习题

这组题专门用于练习：

- 字符串基本操作
- 数字处理
- 字符串与数字转换
- 数组遍历
- 双指针
- 边界条件判断
- 模拟过程

建议前半部分先不要使用 `stoi`、`stringstream` 和正则表达式。

---

## 第一组：字符与字符串基础

### 1. 判断字符串是否全部由数字组成

**示例：**

```text
输入："12345"
输出：true

输入："12a45"
输出：false

输入：""
输出：false
```

**练习点：**

- 字符判断
- 空字符串处理

---

### 2. 统计不同类型字符的数量

- 大写字母
- 小写字母

- 空格
- 其他字符


### 3. 手动实现字符串转整数

不要使用 `stoi`。

**示例：**

```text

输出：12345

输入："00123"
输出：123

输入："12a3"
```

```cpp
value = value * 10 + (ch - '0');
```

- 字符转数字

## 第四组：字符串和数字结合

### 17. 验证 IPv4 地址

**规则：**

- 必须正好有 4 段
- 每段不能为空
- 每段只能包含数字
- 每段范围为 `0～255`
- 不允许前导零，例如 `"01"`

**示例：**

```text
"192.168.1.1"       true
"255.255.255.255"   true
"256.1.1.1"         false
"192..1.1"          false
"192.168.01.1"      false
```

建议拆成两个函数：

```cpp
bool isValidSegment(const string& segment);
bool isValidIPv4(const string& ip);
```

## 每道题的练习流程

写代码前先回答：

```text
输入是什么？
输出是什么？
有哪些非法情况？
需要维护哪些变量？
循环中每个变量表示什么？
```

写完代码后，至少测试四类数据：

```text
正常数据
空数据
边界数据
非法数据
```

例如，“字符串转整数”至少测试：

```text
"123"
"0"
"00123"
""
"12a3"
"-123"
```
